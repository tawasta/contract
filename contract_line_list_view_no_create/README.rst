==============================================
Contract Line List View: Disable Line Creation
==============================================

* Remove the option to create contract lines from list view that is 
  provided by default by contract_line_list_view

Configuration
=============
* None needed

Usage
=====
* Just navigate to Members -> Contract Lines to access the list view.
  Create button does not appear.

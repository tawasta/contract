====================
Website Subscription
====================
* Users can view their own subscriptions in Portal
* A user can end only the subscriptions and subscription lines billed to
  their own company or one of its addresses
* The subscription page shows the invoice address of the subscription with
  the partner's avatar, which shows the initials when there is no image

Configuration
=============
* Portal chatter functionality can be toggled on/off in
  Website editor -> Customize -> Hide Subscriptions Communication Section
* The image of the invoice address is shown by default and can be hidden in
  Website editor -> Customize -> Hide Invoice Address Image
